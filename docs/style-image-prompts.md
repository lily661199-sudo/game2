# ImageGen 風格提案提示詞

**原用途：**ImageGen 風格圖提示詞。  
**目前狀態：**專案負責人選擇不充值 API 點數。由於此工作階段未提供內建 `image_gen` 工具，已改為免費的原創 SVG 風格草圖供挑選。以下提示詞保留作日後可用時參考；現有 SVG 不是 ImageGen 生成圖。

## 固定構圖與世界設定

同一張寬幅 3D 遊戲概念場景：小小的原創旅人站在前景，背著有幾枚發光代幣的布背包、手提燈籠；面前是一個巨大的舊木目標抽屜，幾條窄小路從抽屜旁通往遠方微亮的歸途燈；角落可見簡單的分散式光石托盤，後方是霧港夜色。低機位，巨大房間，小人物，光影引導視線，兼具神秘感與兒童友善，不恐怖、不血腥。無任何文字、logo、浮水印、UI 或既有遊戲角色/場景。每張保持完全相同的道具、鏡位、角色位置和構圖，只變更材質、造型語彙、色彩和渲染技法。

## Prompt 1 — 手工定格動畫微縮模型

Use case: stylized-concept  
Asset type: 兒童教育遊戲的原創 3D 美術方向圖  
Primary request: 使用固定構圖與世界設定，呈現霧港小旅人用背包、目標抽屜、提燈小徑學習先存後花並理解風險分散。  
Style/medium: 手工製作的定格動畫微縮佈景，羊毛氈、舊木、手捏黏土、微微粗糙的實體模型表面，柔和但細節豐富。  
Composition/framing: 固定低機位廣角，超大房間與小旅人比例，角色、抽屜、提燈、道路的位置固定；16:9 寬幅概念圖。  
Lighting/mood: 電影式聚光燈照亮抽屜與旅人，柔和霧氣和溫暖提燈光，四周保持深色，神秘但安心。  
Color palette: 苔綠、煙燻木棕、暖琥珀光、少量霧藍。  
Materials/textures: 可見手工纖維、刷痕、木紋和微小模型接縫，做工精緻。  
Constraints: 全原創，兒童友善；無文字/logo/UI/watermark；無仿作既有遊戲角色或場景；三張提案之間除了風格外構圖與物件一致。
