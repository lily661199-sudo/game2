# 小小夢魔：設計選擇學習單

## 我們要教什麼？

第一關：安排零用錢，留一些給之後想完成的目標。  
第二關：投資可能賺也可能賠；把所有錢放在同一個地方，風險會集中。分散也不能保證不會賠。

## 先想，再看 AI 評分

## 玩完後可以討論

1. 你怎麼決定哪些錢先留下來？
2. 你選的方式可能遇到什麼結果？
3. 你還想知道什麼，才會做更好的決定？
4. 哪個提示或畫面讓你困惑？

這張學習單不記錄姓名或家庭收入；不需要分享真實的零用錢或投資經驗。
